- 简体中文
PEShellBuilder 自定义说明

版本：v1.00 Feature Pack 1

- 自定义工具
位于此目录的 PETools 文件夹里，您可以添加工具

- 自定义壁纸
注意：此设置可能对某些Win11无效
如果是Windows 11，位于此目录的 Wallpaper\11\winre.jpg
如果是Windows 10，位于此目录的 Wallpaper\11\winre.jpg
如果是其他的Windows，位于此目录的 Wallpaper\normal\winre.jpg
可以把现有的winre.jpg替换为您想要的壁纸，分辨率不要超过1024*768

- 自定义欢迎标语
位于此目录的 LaunchBats 文件夹里，您可以把PEShell.bat或PEShell_NotTools.bat中的欢迎标语改为您想要的

- 开机自启
新建一个名为Startup的文件夹，在里面创建PEStartup.bat，里面可以写开机自启的命令和程序
代码千万不要有exit！！！
PEStartup.bat要和程序放到同一个目录（如果没有程序则忽略）

- 自定义程序包
注意：现在Win11的LCU都是wim或msu格式了，仅支持cab格式的程序包
新建名为Packages的文件夹，可以把要添加的cab（包括更新）放到Packages文件夹里

- English
PEShellBuilder Custom Instructions

Version：v1.00 Feature Pack 1

- Custom PE tools
At PETools folder, you can add tools

- Custom PE Wallpaper
Note: This setting might not work on some Windows 11 PE
If it's Windows 11, at Wallpaper\11\winre.jpg
If it's Windows 10, at Wallpaper\10\winre.jpg
If it's Other Windows, at Wallpaper\normal\winre.jpg
You can replace the existing winre.jpg with the wallpaper of your choice, ensuring that the resolution does not exceed 1024*768.

- Custom Welcome Message
At LaunchBats folder，you can edit PEShell.bat or PEShell_NotTools.bat

- Run at startup
Create a Startup folder, in this folder create PEStartup.bat, you can write commands and programs
CODE MUST NOT EXIST EXIT!!!
PEStartup.bat should be placed in the same folder as the program (ignore if there is no program)

- Custom package
Note: Now LCU for Windows 11 all are wim or msu, only supported cab
Create a new Packages folder, you can put the cab files you want to add (including updates) into the Packages folder
